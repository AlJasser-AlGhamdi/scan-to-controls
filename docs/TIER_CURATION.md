# Tier-curation record

The curated classification the toolkit uses is stored, row by row, in
`taxonomy/release/sort_overlay.json`: 18 Tier 1, 127 Tier 2 and 59 Tier 3 rows,
each with its control identifier and evidence tier.

The paper adopts the independent panel's tier where it differs from the curated
one. That moves control 1-2-1 from Tier 3 to Tier 2, so the adopted split is 18
Tier 1, 128 Tier 2 and 58 Tier 3 rows. The panel's pseudonymised votes are
available from the corresponding author on reasonable request.
